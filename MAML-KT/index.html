MAML-KT: Addressing Cold Start Problem in Knowledge Tracing for New Students via Few-Shot Model-Agnostic Meta Learning

A meta-learning approach that makes knowledge tracing more responsive to previously unseen students—by learning model parameters that can personalize with only a small number of observed interactions.

01 / OVERVIEW

Accurate predictions need to start early.

Knowledge tracing estimates what a student knows by observing responses to educational questions. Conventional deep KT methods often learn one set of parameters across historical students. But a new learner starts with almost no history, precisely when early estimates can matter for instructional decisions.

MAML-KT changes the optimization goal. Rather than focusing solely on average training performance, it meta-learns an initialization designed to improve after a few updates on the new student's earliest responses.

“Instead of only learning to predict, the model learns to adapt.
02 / APPROACH

How MAML-KT works

A student-centered adaptation process designed around the natural order of learning interactions.

01 Task definition
◎

One student, one task

Each historical student's question–response trajectory forms a separate meta-learning task.

02 Sequential split
▥

Support then query

Early interactions become the support set; later responses become the query set, preserving chronology.

03 Inner loop
↻

Adapt quickly

Starting from shared parameters, a few gradient steps tailor a GRU-based KT model to each learner.

04 Outer loop
↗

Learn to adapt better

Loss on the remaining interactions improves the shared initialization across student tasks.

Chronological few-shot episode

Support comes first. The query never informs the student's adaptation step.

CRITICAL COLD START
Questions 3–10

MAML-KT achieves higher early prediction accuracy than conventional KT models in nearly all examined cold-start conditions.

The smallest histories are the key test.
MODERATE COLD START
Questions 11–15

Rapid personalization remains competitive as more responses become available, although attention-based models sometimes narrow the gap.

Gains extend beyond the first few questions.
!
Where adaptation is harder

Accuracy can briefly fluctuate when a learner encounters skills that were not present in the adaptation examples. This motivates future skill-aware and novelty-aware adaptation.
