01 / OVERVIEW

How should a model use learning history?

A comparison of model inductive biases, how student history is represented and how performance differs by dataset.

Knowledge tracing predicts students’ future correctness from their earlier question–response interactions. This poster compares approaches that explicitly maintain a memory state with approaches that dynamically attend to relevant past interactions.

It discusses DKT as a recurrent baseline, DKVMN and SKVMN as memory-augmented models, and SAKT and AKT as attention-based models, with published AUC comparisons across ASSISTments datasets.

This is a comparative review and synthesis presented in the LAK companion proceedings. The AUC figures are collated in the poster; they should not be presented as results from a new controlled benchmark implemented for this poster.

DKVMN and SKVMN

DKVMN uses key-value memory slots with read/write operations. SKVMN adds a Hop-LSTM mechanism for relevant long-range sequential dependencies.

SAKT and AKT

SAKT uses self-attention to weight relevant past events. AKT adds context-aware embeddings, monotonic attention and a temporal forgetting mechanism.

Attention wins frequently

SAKT has the highest listed AUC on ASSISTments 2009; AKT has the highest listed AUC on 2012, 2015 and 2017.

But architecture is not destiny

Memory networks have competitive reported AUC, and score differences vary by dataset. The poster does not establish causal superiority of one family under a matched, single evaluation pipeline.

05 / DISCUSSION

Why this comparison matters for cold start

Memory-based KT provides an explicit place to record evolving mastery estimates, but that representation may be difficult to populate for a brand-new student. Attention-based KT can select informative past responses flexibly, but its history is equally limited when the student has answered very few questions.

The poster therefore motivates a natural follow-on question: How can KT adapt rapidly for a student with little or no prior history? This motivation connects the comparison to later new-student and few-shot work.
