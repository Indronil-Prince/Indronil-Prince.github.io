# Research homepage for indronil-prince.github.io

This is a standalone, responsive `index.html` listing all nine publication project pages.

## Publish
1. Open the repository that serves `https://indronil-prince.github.io/`.
2. Place `index.html` in the published site root (typically the repository root on the `main` branch).
3. Confirm **Settings → Pages** points to that branch and directory.
4. Check for a redirect rule or old `index.html` that currently sends the root URL to GitHub; remove or replace the redirect only after backing up the old site.
5. Keep the existing project directories (`MAML-KT`, `cold-start`, and the seven other projects) in the same root.

The root homepage is separate from individual project pages; no CSS assets or dependencies are needed.

**Note:** A few linked project pages may not be live until their folders are uploaded.
